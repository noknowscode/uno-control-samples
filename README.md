# Uno Platform control samples (test copies)

- **Owner:** Matthew Mattei (@noknowscode)
- **Status:** test copies for Uno Platform Studio, under review
- **What it is:** Nine single-control samples for Uno Platform, each built to a Control Gallery design prototype, copied
  here so they can be opened in Uno Platform Studio before review. The reviewed versions will move to
  [Uno.Samples](https://github.com/unoplatform/Uno.Samples); this repository is not a supported release.

Each folder is a self-contained sample with its own solution, `global.json` (Uno.Sdk 7.0.22), `uno-sample.json` and
`.studiolive/`. Its `README.md` explains what it shows and how to run it.
